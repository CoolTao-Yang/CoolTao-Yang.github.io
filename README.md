# Zetao Yang — Personal Homepage

Personal research and career homepage, published at **https://CoolTao-Yang.github.io**.

## Structure

- `index.html` — biography, research interests, news, preprints, experience, education, and awards.
- `style.css` — existing responsive layout and theme.
- `assets/profile-2026-09-10.png` — selected professional portrait, kept in its original PNG format.

The site is static HTML, CSS, and JavaScript. It uses Inter, Font Awesome, and KaTeX from external CDNs; there is no build step.

## Preview and publish

Preview from the repository root with `python3 -m http.server 8765`, then open `http://localhost:8765`.

GitHub Pages publishes the root of the `main` branch. Edit the relevant content, review the diff, commit the selected files, and push to `main`. Verify that the Pages build finishes and the live page reflects the update.

## Content maintenance

Keep biography, experience, education, news, page metadata, and the footer date in sync. The GitHub profile README is maintained separately in [CoolTao-Yang/CoolTao-Yang](https://github.com/CoolTao-Yang/CoolTao-Yang).

Use verified professional facts. Distinguish preprints from accepted publications, and research supervision from authorship. Keep company-internal data, employment contracts, and private contact details out of the repository.
